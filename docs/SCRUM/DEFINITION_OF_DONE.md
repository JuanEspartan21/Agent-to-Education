# Definition of Ready y Definition of Done

## Definition of Ready (DoR)
Una historia puede entrar al sprint cuando:
- Tiene usuario/beneficio claramente descrito.
- Tiene criterios de aceptación verificables.
- Está suficientemente pequeña para completarse en el sprint.
- Se conocen dependencias y datos de prueba.
- No exige datos personales reales para desarrollarse.
- Riesgos de privacidad/seguridad están identificados.
- El PO/cliente entiende el resultado esperado.

## Definition of Done (DoD)
Una historia se considera terminada cuando:
- Código integrado en la rama principal mediante revisión.
- Pruebas unitarias/integración relevantes pasan.
- Manejo de errores y validación de entradas implementados.
- No se introducen secretos ni datos reales del cliente.
- Controles de acceso y clasificación aplicables probados.
- Documentación actualizada.
- Criterios de aceptación demostrados.
- No hay defectos críticos o altos abiertos sin aceptación explícita del riesgo.
- La funcionalidad no degrada el rendimiento objetivo de forma no aceptada.

## Criterios de aceptación transversales
- La aplicación funciona con datos sintéticos.
- La información restringida no sale del dispositivo.
- Las fuentes se citan con versión y ubicación.
- El docente conserva aprobación final.
- El sistema distingue hechos, inferencias y recomendaciones.
- Los registros técnicos no contienen contenido sensible.
